minichlink Windows x64
======================

실행 파일: minichlink.exe (64-bit Windows 콘솔 프로그램)

실행하려면 minichlink.exe와 libusb-1.0.dll을 같은 폴더에 두세요.

명령 프롬프트에서 실행 예:
  minichlink.exe -C usbasppico -g 0

일반 사용법:
  minichlink.exe -h

USB 장치가 검색되지 않으면 Windows 장치 관리자에서 해당 USB 인터페이스에
WinUSB 드라이버가 설치되어 있는지 확인하세요. 이 실행 파일은 USB 장치 연결을
실제로 테스트하지 않았습니다.
